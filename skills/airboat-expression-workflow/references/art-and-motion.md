# 美术、动作和过渡

## 准备与完成信号

准备当前工作台、原 GIF/EAF、用户认可的片段和目标语义。先看完整动画，再暂停到问题帧。输出是一组能从绿色待机进入、完整表演并回来的动作；看得出原来的性格，小屏也能读懂。

## 把用户反馈变成局部任务

| 反馈 | 处理范围 | 要保留的特征 |
| --- | --- | --- |
| 「有瑕疵」「瞳孔跳」「不流畅」 | 找到缺口、拆层或采样跳变，再补帧/修合成 | 眼形、大小眼差异、动作幅度、节拍 |
| 「不够灵动」 | 加预动、错拍、短停、轻重不同的回弹 | 已认可的美术、首尾锚点 |
| 「重新设计这段过渡」 | 改这段眼睑/瞳孔形变过程 | 进入后的表情性格及其他动作 |
| 「这两个共用」 | 素材引用映射和去重；语义节点分别保留 | 原事件名称、入口、优先级与业务含义 |
| 「底色闪烁」 | 比较源图 alpha 与不透明遮罩，查看边角及装饰 | 仅清理伪背景像素，眼白/瞳孔姿态逐帧不变 |

历史教训：为修五个表情的瑕疵，把它们改成通用眼睑动画，虽然软件检查通过，用户仍指出思考、好奇、摇摆、搞怪失去原味。恢复原 GIF 和 `SCORES` 后，再局部修轮廓与采样。

## 动作谱怎么写

为每个动作分别写眼睛整体、眼睑、瞳孔和装饰的轨迹，列出「何时开始、到哪、停多久、怎么回」。使用毫秒关键点和位置/高度变化，插值后按 25 fps 采样。

| 表演 | 主节拍 | 细节的独立节拍 |
| --- | --- | --- |
| 开心 | 压低蓄力 → 弹起稍停 → 再轻弹 → 回稳 | 两眼略错拍，黑色笑弧稍晚跟上 |
| 晕眩 | 一次主摆 → 左右交替余震 → 回稳 | 余震振幅递减，瞳孔/装饰晚于眼形 |
| 张望/好奇 | 瞳孔先看 → 眼形跟上 → 驻留 → 收回 | 眼形尚未移动时，瞳孔已有清晰方向 |
| 默认待机 | 小瞥视 → 慢眨回弹 → 另一侧小瞥 → 双眨 | 第二眨更浅更快，间隔留安静，回中对称 |
| 大笑 | 下眼睑抬起 → 遮瞳孔 → 月牙 → 两次回弹 | 右眼晚一帧，爱心晚于眼睛，收尾逐渐睁开 |
| 疲惫 | 大幅下沉 → 撑两下 → 憋气抬眼 → 再垂下 | 低点小颤、抬起短停，不能把累感磨平 |
| 难过 | 目光先低 → 眼形垂 → 轻微吸气 → 抬眼 | 停顿中仍有小幅变化，避免僵住 |
| 哭泣 | 忍住 → 轻颤 → 两滴泪错开落下 → 平复 | 泪珠有完整轮廓、渐显渐隐和加速下落 |

选择 `expression_repertoire.py` 的 `SCORES/DELAYS` 保留已有动作；轮廓修补用 `expression_source_repair.py`；新眼睑研究用 `expression_lid_study.py`。不要为统一实现把这些表演套成相同幅度和时长。

## 首尾与打断

完整时序为 `共享待机 → entry → performance → exit → 共享待机`。微动作 contour 包进入与收尾各 9 帧；Square Pop authored package 各 19 帧，具体以 manifest 的 `transition_frames` 为准；均为 25 fps。主体帧数按 clip 定义。区间按 `[start,end)` 解释。

- 进入的末帧对齐主体首帧，主体末帧对齐收尾首帧；循环首尾也要对齐。
- 主体循环按主体区间推进，不要把每次循环都播成「进入—退出」。
- 运行中切换情绪，以当前姿态为起点接下一情绪。完整播放和中途切换是两项验收。
- 背景通过短 HSV 色相路径变色；眼形和装饰有自己的过渡时机。全部首帧一致只是接口，不能替代整段表演。

## 造型、镜像与制作规范

画布使用 480×480 全脸母版。眼白、黑瞳孔、彩色装饰和纯色背景分开。曲线以超采样生成再缩回母版，边缘保留 4 bit 覆盖度（16 级），不要先二值化再靠放大补清晰度。

眼形共享不强迫瞳孔镜像：居中待机可以左右镜像，小瞥视时双瞳应向同一方向移动。完整脸素材按自身双眼布局绘制；原版窄单眼素材才按对应布局做配对镜像。工作台默认显示设备实际镜像状态，允许用户切换。

惊讶、疲惫的极端姿势和全部装饰都要在画布范围内。惊讶原图下缘曾到 y=426，沿用旧 y=394 的裁切会截断。以实际像素边界检查，圆屏适配另看圆周和字幕位置。
